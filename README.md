<h1 align="center">Prerequisites (Color Variables Setup)</h1>
<p align="center">
Before using Dusk, organize your color variables in Light and Dark groups.<br>
Swatch naming format msut be like<br>
Category / Tone / Name<br>
  <br>
Example:
	•	Brand / Light / Primary<br>
	•	Brand / Dark / Primary
</p>
<p align="center">
  <img src="assets/screenshot-2.png" width="900"/>
</p>

<br>
<h1 align="center">How to Use</h1>
<p align="center">
Select any Frame, Symbol, or Layer<br>
Go to Plugins → Dusk → Switch Theme<br>
Your design will instantly switch to Light or Dark
</p>
<br>
<br>
<h1 align="center">Features</h1>
<p align="center">Light ↔ Dark theme switching •	Works with Color Variables •	Supports Symbols •	Supports Overrides •	Supports Gradients •	Supports Shadows •	Works with Library Styles •	Fast and safe conversion •	Built for Design Systems
</p>
<br>
<br>
<h1 align="center">Installation</h1>
<p align="center">
  Download the plugin using the button above<br>
  Unzip the file<br>
  Double click dusk.sketchplugin<br>
  Open Sketch<br>
  Go to Plugins → Dusk
</p>
